## Почему Lumela?

Сырой скриншот редко выглядит достаточно хорошо, чтобы им поделиться. Lumela за один шаг превращает его в аккуратное изображение: подходящий фон, сбалансированные отступы, скруглённые углы и мягкая тень. Стрелки и текст поясняют главное, а конфиденциальные данные размываются до того, как их кто-то увидит.

- **Всё бесплатно.** Без аккаунтов, подписок и водяных знаков.
- **Приватность прежде всего.** Снимок, распознавание текста и скрытие данных выполняются на вашем устройстве. Ничего не загружается в сеть.
- **Быстро.** Нативный захват экрана и небольшой установщик (около 4 МБ для Windows, 12 МБ для macOS).
- **Одно приложение везде.** В Windows, macOS и Linux одинаковые редактор, горячие клавиши и функции.

## Скачать

Скачайте установщик для своей системы из [последнего релиза](https://github.com/tw4/lumela/releases/latest):

| Система | Файл |
|---|---|
| Windows 10 / 11 (x64) | `Lumela_<version>_x64-setup.exe` или `.msi` |
| macOS 10.15+ (Apple silicon и Intel) | `Lumela_<version>_universal.dmg` |
| Linux (x64): Ubuntu 24.04+, Debian 13+, Fedora 40+ или аналогичные | `Lumela_<version>_amd64.AppImage` или `.deb` |

Или установите через менеджер пакетов:

```bash
brew trust tw4/tap && brew install --cask tw4/tap/lumela                             # macOS (Homebrew)
scoop install https://raw.githubusercontent.com/tw4/lumela/main/packaging/scoop/lumela.json   # Windows (Scoop)
```

Lumela проверяет новые версии в фоне и предлагает обновиться в один клик: скачивает, проверяет подпись, устанавливает и перезапускается. Ничего не нужно удалять и скачивать заново. В Linux это работает с AppImage; для `.deb` кнопка обновления открывает страницу релиза.

> [!NOTE]
> Установщики пока не подписаны сертификатом, поэтому при первом запуске система показывает предупреждение.
>
> **Windows:** *Подробнее* → *Выполнить в любом случае*.
>
> **macOS 15 и новее:** откройте Lumela один раз и закройте предупреждение, затем перейдите в **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть** рядом с сообщением о Lumela. В macOS 14 и старше достаточно правого клика по приложению → *Открыть*. При установке через Homebrew этот шаг не нужен.
>
> **Linux:** пакет `.deb` устанавливает `tesseract-ocr` для распознавания текста. Для AppImage установите его сами (`sudo apt install tesseract-ocr`, `sudo dnf install tesseract` или `sudo pacman -S tesseract tesseract-data-eng`).

## Возможности

| | |
|---|---|
| **Захват** | Область, окно (нажмите <kbd>Пробел</kbd> во время захвата) или весь экран, глобальные горячие клавиши и меню в трее. Несколько мониторов. Открытие из файла, буфера обмена или перетаскиванием. |
| **Оформление** | Автоматический фон по цветам краёв скриншота, автобаланс, градиенты, сплошные цвета, своё изображение или обои рабочего стола, отступы, внутренний отступ, скругление углов и тень. |
| **Размеры** | Свободный, 1:1, 4:3, 3:2, 16:9, 9:16 и пресеты для X/Twitter, Instagram, LinkedIn, Facebook и YouTube. |
| **Пометки** | Стрелки (прямые, изогнутые, двойные, линия), текст, прямоугольники, эллипсы и выделение. Перемещение, изменение размера, порядок слоёв, отмена/повтор. |
| **Скрытие данных** | Пикселизация, размытие или сплошная заливка. **Автоскрытие** одним кликом находит адреса почты, номера банковских карт, IP-адреса и API-ключи. |
| **Копирование текста** | Распознавание текста на устройстве: выделите слова на изображении и скопируйте их. |
| **Экспорт** | Копировать, сохранить, сохранить как PNG/JPEG или перетащить прямо в другое приложение. Сжатие PNG без потерь. Водяной знак по желанию. |
| **Организация** | Пресеты, история скриншотов вместе с правками и настраиваемые горячие клавиши. |
| **Язык интерфейса** | Английский и турецкий. [Добавьте свой!](CONTRIBUTING.md#translations) |

Горячие клавиши, сборка из исходников и участие в разработке описаны в [README на английском](README.md).

## Конфиденциальность

В Lumela нет аккаунтов и телеметрии. Скриншоты, история и настройки остаются на вашем компьютере. Единственный сетевой запрос — проверка обновлений в релизах этого репозитория.
